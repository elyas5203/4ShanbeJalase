# Avatar Images

این پوشه شامل تصاویر آواتار برای شخصیت‌های مختلف چت است.

## فایل‌های مورد نیاز:

- `user.png` - آواتار کاربر عادی
- `admin.png` - آواتار مدیر سیستم
- `karagah.png` - آواتار کاراگاه (شخصیت اصلی)
- `hacker.png` - آواتار هکر
- `system.png` - آواتار سیستم
- `default.png` - آواتار پیش‌فرض

## مشخصات تصاویر:

- اندازه: 64x64 پیکسل (حداقل)
- فرمت: PNG (برای شفافیت)
- شکل: مربع (به صورت خودکار دایره می‌شود)
- کیفیت: بالا

## نحوه استفاده:

فقط فایل‌های تصویری را با نام‌های مشخص شده در این پوشه قرار دهید.
سیستم به صورت خودکار آن‌ها را به عنوان آواتار استفاده خواهد کرد.

اگر تصویری یافت نشود، ایموجی پیش‌فرض نمایش داده می‌شود.
