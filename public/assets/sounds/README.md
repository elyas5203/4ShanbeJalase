# صداهای بازی کاراگاه

## فهرست فایل‌های صوتی

### صداهای تایپ
- `type1.mp3` - صدای تایپ اول
- `type2.mp3` - صدای تایپ دوم  
- `type3.mp3` - صدای تایپ سوم

### صداهای اثرات
- `ajir.mp3` - صدای آژیر هشدار
- `khande.mp3` - صدای خنده اول
- `khande2.mp3` - صدای خنده دوم

## نکات مهم
- تمام فایل‌های صوتی باید در فرمت MP3 باشند
- حداکثر اندازه هر فایل: 5MB
- کیفیت توصیه شده: 128kbps
- مدت زمان صداهای تایپ: 0.1-0.3 ثانیه
